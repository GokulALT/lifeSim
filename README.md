# Life Simulator

A text-based life simulator in the style of BitLife. You play one character from birth to death. Each tap of **Age Up** advances a year, updates stats, career, and finances, and serves a life event with choices. Common and uncommon events come from seeded templates. Rare events are generated by an LLM.

## Stack

- Next.js 15 (App Router) with TypeScript (strict mode)
- Tailwind CSS v4
- Zustand for client state
- Zod for validation
- MongoDB through the native driver (v6)
- NextAuth v5: credentials with bcrypt and JWT sessions
- OpenAI SDK pointed at NVIDIA NIM, used for rare AI events
- Vitest and Testing Library

## Setup

1. Install dependencies:

   ```bash
   npm install
   ```

2. Copy `.env.local.example` to `.env.local` and fill in these values:
   - `MONGODB_URI`: a MongoDB connection string, such as an Atlas cluster.
   - `AUTH_SECRET`: run `npx auth secret`, or use any random string of 32+ characters.
   - `NVIDIA_API_KEY`: optional. Without it, rare events fall back to the static uncommon and common pools. `AI_MODEL` overrides the default model.

3. Seed the event templates and create indexes, including the unique index on user email:

   ```bash
   npm run seed
   ```

4. Start the dev server:

   ```bash
   npm run dev
   ```

   Open http://localhost:3000, register, and start a life.

## Tests

```bash
npm run test:run
```

## Self-hosting

For `next build && next start` outside Vercel, set `AUTH_TRUST_HOST=true` so NextAuth accepts the host header.
